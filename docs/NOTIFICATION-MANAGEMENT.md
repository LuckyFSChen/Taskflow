# 通知紀錄管理

管理者可在「平台設定 → 雲端收件服務・通知紀錄」查看一般通知、聊天／互動回覆及服務指令回覆。

- 按未送出、等待傳送、傳送失敗、傳送中、處理指令中、已送出及已取消篩選；可搜尋內容與收件人，每頁 20 則。
- 單筆或勾選多筆「取消待送」，確認後停止後續傳送，保留內容、取消時間與操作人。這不會取消任務、停止重啟指令或撤回 LINE 訊息。
- 失敗通知可重新排入重試，沿用原通知識別碼；不重新執行任務或服務操作。LINE 額度用完時，重試仍可能失敗。
- 傳送中及尚在處理的服務指令不能取消。發送端先取得原子傳送鎖，避免取消與發送同時發生。
- 待送佇列與歷史保存在本機 SQLite，雲端收件服務負責中繼。已送出表示 LINE API 接受，不代表手機已讀；舊資料未保存的建立／送出時間不會補造。

介面僅限管理者；變更 API 需要登入、管理者權限、CSRF 檢查及明確確認。回傳資料不包含 LINE reply token 或完整 LINE ID。

## 驗證

完整 `npm test` 的 138 項測試及 `npm run build` 通過。新增測試包含篩選與分頁、取消歷史、重試、傳送競態、服務指令狀態、權限及 CSRF。

`node scripts/preview-notification-admin.js` 提供獨立暫存資料庫、24 則假通知及本機 14313 測試頁，不啟動發送器。瀏覽器已驗證搜尋、取消確認及歷史、分頁、失敗重試轉為等待傳送，未取消正式待送訊息。

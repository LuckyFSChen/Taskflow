# 額度切換與工作交接

TaskFlow 預設在 Claude 或 Codex 回報額度限制時，於下一次排程改用另一個未處於額度等待期的引擎，繼續同一步驟。原本設定的規劃／執行／驗證引擎仍作為優先選擇。並非所有錯誤都切換；權限、網路、套件與程式錯誤仍回報處理。

兩個引擎均受限時，選擇最早可重試的時間等待。Claude 可解析的時区恢復時間依供應商訊息設定；未提供明確時間時，15 分鐘後重新檢查，不宣稱屆時一定恢復。停止、取消與計畫審核仍有效。

所有引擎共用原工作副本。每次執行前產生 `.taskflow/handoff.json`，包含該任務的完整資料庫活動紀錄（不限畫面最近 300 筆）、歷次角色結果／錯誤、目前核准計畫與歷次問答。接手引擎須先閱讀並核對檔案，保留已完成成果，再繼續未完成部分。這是已保存的工作紀錄交接，不是供應商內部隱藏推理或原始對話狀態的轉移。

驗證：109 項測試通過，涵蓋双向切換、兩邊受限等待、未知恢復時間、手動停止、審核邊界、獨立驗證階段、部分檔案保留及超過 300 筆活動交接。

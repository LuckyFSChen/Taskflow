# LINE 快捷操作

2026-09-16 已部署快捷選單，LINE API 確認它是此 Bot 的預設 rich menu。

## 使用方式
在手機 LINE 關閉並重新開啟 Bot 聊天視窗；若選單收合，點聊天底部「任務快捷選單」。固定選單及 Quick Reply 主要供手機 LINE 使用。

- **發布任務**：選專案 → 選程式／研究文件 → 輸入標題 → 輸入需求 → 確認發布。專案、類型與確認均點選，不需輸入代號或指令。
- **任務進度**：查看自己的任務，再點選任務看詳情。
- **待我審核**：查看待審核、需回答或失敗的任務；先閱讀完整計畫，再點「核准此版計畫」或「回答／修改需求」。
- **工作台**：目前提示在 Windows 開啟本機網站。只有 PUBLIC_ORIGIN 設為外部 HTTPS 網址後，才提供手機可點的網頁連結。

填寫流程保留 30 分鐘，會保存在資料庫。可隨時取消。過期或上一個流程的按鈕不能繼續發布；重複點選確認或 LINE 事件重送不會建立重複任務。仍需 Windows 平台在線，Bot 才會處理互動；平常同步間隔約 10 秒。

首次綁定仍需在網頁產生一次性連結碼；完成後使用快捷選單。既有文字指令保留供相容使用，新的通知不再要求使用者手打指令。

## LINE 建立專案

管理者在平台設定儲存「預設專案存放位置」，然後在 LINE 的回覆快捷按鈕點「建立專案」。也可先按底部「發布任務」或「工作台」，取得含此功能的新回覆。輸入名稱、確認路徑後，會建立同名資料夾並自動加入平台專案；完成後可直接點「在此發布任務」。不需要手動輸入專案代號。

名稱不可包含路徑分隔符號、Windows 保留名稱或結尾句點；同名專案／資料夾會拒絕並要求重新命名。過期、重播或取消的確認不會重複建立。設定位置在填寫途中改變時必須重新開始。僅管理者可以建立專案，一般成員沿用既有專案授權。電腦關機時訊息保留於雲端，重新上線後才會處理。

## 修改任務狀態

LINE → 任務進度 → 選擇任務，可點「標記完成」「暫停任務」「取消任務」「恢復處理」。查看任務後也可回覆同名文字，「結束任務」等同手動標記完成。未選擇任務時不會猜測目標。

與網頁共用狀態更新機制，正在執行的 AI 會收到停止要求。手動完成會明確標示，不能視為 AI 驗證通過。只允許操作自己的任務；按鈕與文字上下文 30 分鐘過期，任務狀態／計畫版本更新後需重新查看。重送事件不會重複操作。

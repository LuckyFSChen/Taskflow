## LINE 通知

正式環境 idv-web 通知已建立，但 `sent=0`、回報 `LINE HTTP 429`。透過經驗證的唯讀額度查詢，LINE 官方帳號目前回傳 `type=limited, limit=200, used=200`，推播額度已用完。

一般聊天可用有效的 webhook reply token 直接回覆；幾分鐘後才產生的任務通知依賴推播，不能重用已過期的 token。程式不能解除帳號額度限制，也不會自行購買或變更方案。原通知保留在重試佇列；恢復額度後依既有退避排程重試。
